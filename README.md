 Customer-Segmentation Using K-Means

Developed a Customer Segmentation model using the K-Means clustering algorithm to group mall customers based on their Annual Income and Spending Score. The project analyzes customer purchasing behavior and identifies distinct customer segments such as high-income/high-spending, low-income/low-spending, and other behavioral groups. This segmentation can help businesses understand customer profiles and design targeted marketing strategies, personalized offers, and customer engagement plans.

Tools/Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, K-Means Clustering, Elbow Method.

Dataset: 200 customers with attributes including Age, Gender, Annual Income, and Spending Score.
